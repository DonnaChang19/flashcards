进入后台 →

使用说明

  • 学生：打开任意闪卡 → 输入老师发放的学习 Key → 进度自动同步到云端，换设备或清理浏览器缓存后仍可恢复（每台设备首次登录需绑定）。
  • 老师：进入「老师后台」用教师 Key 登录，查看学生完成情况、高频错误术语（可按具体学生筛选）与 Key 管理。
  • 复习：系统按错误次数加权（易错优先），薄弱项会更高频出现；「通盘 / 按章」模式保持源顺序。
  • 未登录时仍可离线使用，进度仅保存在本机浏览器。
